# 鳄鱼形象 v2 · 重新设计（SPEC）

> 状态：待确认切面 → 实施
> 来源：用户提供 3 张参考图（[docs/reference/croc-style/](reference/croc-style/)），要求「以这些鳄鱼形象为参考，重新设计本项目的新鳄鱼」。
> 关联：[docs/SPEC.md](../SPEC.md) FR-CROC-01/02/03、[docs/adr/0003-one-croc-six-actions.md](../adr/0003-one-croc-six-actions.md)、[GLOSSARY.md](../../GLOSSARY.md)。
> 注：仓库尚未配置 issue tracker（无 `.github`、无 `gh` CLI），本 spec 先落盘到 `docs/specs/`；如需发布到 tracker，先运行 `/setup-matt-pocock-skills` 提供工具与标签词表。

## Problem Statement

现在设备右下角那只鳄鱼是早期用方块拼出来的占位图：轮廓方、没有脖子和肚子、五官只有两个点，六个动作之间主要靠道具差异（笔记本/问号/星星）区分，鳄鱼本身几乎一样。用户给了三张卡通鳄鱼参考图——圆头、厚黑描边、白色高光眼、短吻、浅色肚皮、表情夸张——希望「鳄鱼大宠物」的主角真正长成这个样子：一眼能认出是同一只角色，且每个状态有不同姿态和表情。墨水屏只有黑白两色、400×300，形象必须在不加灰阶、不加动画的前提下保持可读。

## Solution

按参考图重画六动作鳄鱼素材，仍走既有素材契约：`assets/croc/default/<action>.png`，30×40 单色 PNG，3× 最近邻放大到 90×120，画在 (300,150)。版式、状态机、刷新策略、配置全部不动。新形象采用「厚描边卡通」风格：圆头 + 短吻 + 高光眼 + 浅色肚皮 + 粗四肢，六动作各有可辨认的剪影与表情（待命端咖啡杯、干活敲笔记本、等你举手/问号、完成星星/点赞、出错绷带/× 眼、睡觉闭眼 + Z）。同步把插件图标换成新鳄鱼头像，更新 README 与截图，并把 3 张参考图收进仓库作为风格出处。

## User Stories

1. 作为设备主人，我希望鳄鱼是圆头、厚描边的卡通形象，而不是方块拼图，这样一眼能认出它是个有性格的角色。
2. 作为设备主人，我希望六种状态下的鳄鱼姿势明显不同，这样不用读文字也能知道 DSH 在干什么。
3. 作为设备主人，我希望待命时鳄鱼在喝咖啡，这样「等你派活」的感觉更轻松。
4. 作为设备主人，我希望干活的鳄鱼在敲笔记本电脑，这样和「正在工作」一致。
5. 作为设备主人，我希望等你处理时鳄鱼举手或头顶问号，这样我能看出它在等我。
6. 作为设备主人，我希望完成时鳄鱼有星星或点赞的表情，这样完成有正反馈。
7. 作为设备主人，我希望出错时鳄鱼有绷带或 × 眼，这样异常一眼可见。
8. 作为设备主人，我希望睡觉时鳄鱼闭眼并出现 Z，这样长时间没任务时它像在休息而不是死机。
9. 作为设备主人，我希望新形象在单色墨水屏上对比清楚，不糊成一团黑。
10. 作为设备主人，我希望新形象保持 90×120 大小，不挤占标题和底部信息。
11. 作为设备主人，我希望新形象不遮挡文字、不超出画布。
12. 作为设备主人，我希望鳄鱼的默认形象和插件图标、README 配图是同一个角色，品牌一致。
13. 作为设备主人，我希望图标在小尺寸（128×128）也认得出来。
14. 作为设备主人，我希望以后提供自己的画作时能直接替换同样 6 个文件，不用改代码。
15. 作为设备主人，我希望参考图的风格被保留（圆头、粗描边、高光眼、浅色肚皮），而不是换成另一种画风。
16. 作为设备主人，我希望装扮（outfit）机制仍然存在，未来可以出「咖啡师鳄鱼」「程序员鳄鱼」整套皮肤。
17. 作为设备主人，我希望素材的来源和使用在文档里写清楚，避免版权问题。
18. 作为设备主人，我希望预览命令能直接渲染六动作，方便我确认画面而不必每次都推真机。
19. 作为设备主人，我希望真机上看到的和预览一致。
20. 作为设备主人，我希望动作切换时才重绘，不要为了动画每帧都刷屏。
21. 作为设备主人，我希望睡觉动作只在长时间无任务时出现，而不是一待命就睡。
22. 作为设备主人，我希望错误/停止状态都有明确表情，而不是共用一张图。
23. 作为设备主人，我希望鳄鱼的身体比例稳定（头大身小），六张图看起来是同一只。
24. 作为设备主人，我希望描边粗细在 3× 放大后一致（屏上约 3px），不会有的粗有的细。
25. 作为设备主人，我希望表情（眼睛、嘴）是区分动作的主要手段，道具是辅助。
26. 作为开发者，我希望形象重做只改素材文件，不改 `sprite` 渲染逻辑，这样改动面最小。
27. 作为开发者，我希望有单元测试保证六动作素材存在、可解码、有墨、不越界。
28. 作为开发者，我希望预览图和真机照片作为验收证据写进 SPEC。
29. 作为开发者，我希望素材生成过程可复现（脚本 + 源 PNG 入库），而不是只有结果文件。
30. 作为开发者，我希望旧占位图被完全替换，仓库里不再有混淆视听的旧素材。
31. 作为开发者，我希望版本号按素材变更递增（0.6.1），并同步插件 package.json 与 SPEC。
32. 作为未来维护者，我希望参考图、风格规则、验收标准集中在一处，替换素材时知道要满足什么。

## Implementation Decisions

**切面（seams）**：不新增切面。唯一改动点是既有素材契约 `assets/croc/default/<action>.png` 与 `sprite::draw_action` 的加载路径；测试复用 `src/sprite.rs` 现有单元测试位置；视觉验收复用 `dsh-pet preview` 与真机推送。版式、状态机、配置、插件协议不改。

**风格规则（v2）**
- 剪影优先：先保证 30×40 下轮廓可辨，再补 1px 描边与表情；不靠灰度、不靠抗锯齿。
- 厚描边：素材内 1px 实心描边，3× 放大后在屏上约 3px。
- 比例：头约占身高 40%，圆头短吻，眼白/高光各占 1–2px；肚皮浅色（白底 + 2–3 条短横线）。
- 道具：只保留一个主道具，放在手边/桌面上，不能盖住头和眼睛。
- 六动作语义：`idle` 端咖啡杯（呼应参考图「早上好」）；`working` 敲笔记本电脑；`waiting` 举手/头顶问号；`done` 星星或点赞（呼应「奈斯」）；`error` 绷带或 × 眼；`sleep` 闭眼 + Z。
- 停止（Stopped）沿用 error 动作（既有决定，不改）。

**素材与代码**
- 六个文件名不变，路径不变，尺寸仍 30×40、格式仍单色 PNG（`L` 模式）。
- 不用更高分辨率：虽然 45×60@2× 能画更多细节，但用户已定 30×40 契约（ADR 0003 / Q13），本轮遵守；细节靠剪影和表情表达。
- 生成方式：提供可复现脚本（Python + PIL，放进 `scripts/`），源 PNG 入库；脚本只生成黑白像素，不用灰度抗锯齿。
- 图标：`plugin/icon.png` 换成新鳄鱼头像（128×128 单色），保持 `./icon` 导出与 `files` 打包不变。
- 文档：README 头图、`docs/screens/` 下的截图用新形象重渲染；`docs/reference/croc-style/` 保存 3 张参考图并注明「用户提供的风格参考，不直接复制」。
- 版本：Cargo 与插件 package.json 同步 0.6.1；SPEC 的 FR-CROC 证据更新，新增 FR-CROC-05「形象 v2 风格基线」。

**接口**：`sprite::draw_action(elements, x, y, action, scale) -> usize` 不变；`ACTIONS` 常量不变；`assets/croc/<outfit>/<action>.png` 目录约定不变。

## Testing Decisions

- 好的测试只验证外部行为：素材存在、可解码、有墨、尺寸正确、六动作齐全、未知动作不画、场景不越界；不比对具体像素（手绘素材会反复微调，golden 测试太脆）。
- 测试位置：`src/sprite.rs` 现有测试模块（`all_actions_have_art`、`unknown_action_draws_nothing` 等）扩展；版式层已有 `layouts_obey_hub_limits` 覆盖越界。
- 新增断言建议：每个动作的墨点比例在 8%–55% 之间、包围盒在 30×40 内且宽高 ≥ 10×16（保证不是一团噪声或空图）；六动作两两不同（简单哈希/矩形集合不同）。
- 视觉验收：`preview --demo <state>` 生成 400×300 PNG 人工比对参考图风格；真机推六状态各一张，确认对比度与辨识度。
- 性能：维持贪心矩形化，单帧矩形数 < 220（现有布局上限测试 200 个元素，素材最多增加几十个矩形，需实测后必要时调上限或简化素材）。

## Out of Scope

- 彩色墨水屏、灰阶渲染、逐帧动画/眨眼；四色或 gray4 下的形象差异。
- 新动作（如「听语音」「等授权」独立形象）——继续复用六动作。
- 装扮（outfit）内容实现：只保留目录机制，不产出第二套装扮。
- 版式调整、品牌头、底部文案、手势、语音、插件设置页。
- 参考图的二次创作版权归属之外的商用授权。

## Further Notes

- 三张参考图的关键特征：薄荷绿圆头鳄鱼、黑粗描边、白色高光眼、短吻带两颗小牙、浅黄/白肚皮、表情夸张（咖啡师「早上好」、点赞「奈斯」、打工「沉迷工作」）。v2 只取这些造型语言，不描摹具体画面。
- 墨水屏约束：30×40 单色、3× 最近邻放大，灰阶抗锯齿会被阈值成二值，因此素材必须直接画成黑白实心形状。
- 素材验收后，SPEC 的 FR-CROC-01/02/03 证据换成新预览 PNG + 真机照片；`docs/adr/0003` 追加「v2 风格基线」备注。
- 若实施时发现 30×40 下某动作（尤其 waiting/error）辨识度不足，优先简化道具与姿势，而不是改尺寸契约；确需改尺寸时另开 ADR 并回来对 spec。

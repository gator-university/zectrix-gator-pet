# 鳄鱼形象 v2 · 重新设计（SPEC）

> 状态：已确认切面 → 待实施
> 来源：用户提供 3 张参考图（[docs/reference/croc-style/](reference/croc-style/)），要求「以这些鳄鱼形象为参考，重新设计本项目的新鳄鱼」。
> 追加决定：素材改为 **90×120 直接绘制**（不再 30×40 放大）；左上品牌行加英文产品名 **「Zetrix / DSH pet」**。
> 关联：[docs/SPEC.md](../SPEC.md) FR-CROC-01/02/03/05、FR-UI-05、[docs/adr/0003-one-croc-six-actions.md](../adr/0003-one-croc-six-actions.md)、[GLOSSARY.md](../../GLOSSARY.md)。
> 注：仓库未配置 issue tracker，本 spec 与 tickets 按 skill 的本地文件模式落盘（`docs/specs/`、`.scratch/`）。

## Problem Statement

现在设备右下角那只鳄鱼是早期用方块拼的 30×40 占位图：轮廓方、没有脖子和肚子、五官只有两个点，六个动作主要靠道具区分，鳄鱼本身几乎一样；3× 最近邻放大后边缘也很粗。用户给了三张卡通鳄鱼参考图——圆头、厚黑描边、白色高光眼、短吻、浅色肚皮、表情夸张——希望「鳄鱼大宠物」的主角真正长成这个样子，而且细节要经得起 90×120 的展示尺寸。同时左上角只有中文品牌名，用户希望旁边/下面同时出现英文产品名 "Zetrix / DSH pet"，让产品在 DSH 生态里有正式英文标识。

## Solution

1. **素材契约升级**：鳄鱼素材改为 90×120 单色 PNG，按 1:1 画在 (300,150)（不再 3× 放大）。渲染路径不变（`sprite::draw_action` 贪心矩形化），只改素材尺寸与缩放参数；`scale` 参数保留但 v1 传 1。
2. **六动作 v2 形象**：主角是 **gator（短吻鳄 / alligator）**——短而圆的 U 形吻部、圆头、厚描边、高光眼、浅色肚皮，不是长尖吻的 croc；待命端咖啡（「早上好」参考）、干活敲笔记本（「沉迷工作」参考）、等你举手/问号、完成星星/点赞（「奈斯」参考）、出错绷带/× 眼、睡觉闭眼 + Z。90×120 有足够像素画 2px 描边和表情。
3. **品牌行**：左上第一行中文「鳄鱼大宠物」12px，第二行英文「Zetrix / DSH pet」9px；分隔线下移，版式其余元素顺势下移几个像素，不挤压底部信息。
4. **配套更新**：插件图标换成新鳄鱼头像（128×128）；README 头图、`docs/screens/` 截图重渲染；SPEC 证据与版本（0.6.1）同步。

## User Stories

1. 作为设备主人，我希望鳄鱼是圆头、厚描边的卡通形象，而不是方块拼图，这样一眼能认出它是个有性格的角色。
2. 作为设备主人，我希望形象直接用 90×120 绘制，这样屏幕上能看到眼睛高光、牙齿、肚皮条纹这些细节。
3. 作为设备主人，我希望六种状态下的鳄鱼姿势明显不同，这样不用读文字也知道 DSH 在干什么。
4. 作为设备主人，我希望待命时鳄鱼在端着咖啡，这样「等你派活」的感觉更轻松。
5. 作为设备主人，我希望干活的鳄鱼在敲笔记本电脑，这样和「正在工作」一致。
6. 作为设备主人，我希望等你处理时鳄鱼举手或头顶问号，这样我能看出它在等我。
7. 作为设备主人，我希望完成时鳄鱼有星星或点赞表情，这样完成有正反馈。
8. 作为设备主人，我希望出错时鳄鱼有绷带或 × 眼，这样异常一眼可见。
9. 作为设备主人，我希望睡觉时鳄鱼闭眼并出现 Z，这样长时间没任务时它像在休息。
10. 作为设备主人，我希望新形象在单色墨水屏上对比清楚，灰阶阈值化后也不糊。
11. 作为设备主人，我希望新形象保持 90×120 占位，不挤占标题和底部信息。
12. 作为设备主人，我希望鳄鱼不遮挡文字、不超出画布、不压到底部线。
13. 作为设备主人，我希望左上同时看到中文「鳄鱼大宠物」和英文「Zetrix / DSH pet」。
14. 作为设备主人，我希望中英文都小到不抢状态大字的视觉焦点。
15. 作为设备主人，我希望中英文是同一品牌行的两个层次（中文主、英文副），而不是两个争抢的标题。
16. 作为设备主人，我希望鳄鱼的默认形象和插件图标、README 配图是同一个角色。
17. 作为设备主人，我希望图标在 128×128 也认得出来。
18. 作为设备主人，我希望以后提供自己的画作时能直接替换同样 6 个 90×120 文件，不用改代码。
19. 作为设备主人，我希望参考图的风格被保留（圆头、粗描边、高光眼、浅色肚皮），而不是换成另一种画风。
20. 作为设备主人，我希望装扮（outfit）机制仍然存在，未来可以出整套皮肤。
21. 作为设备主人，我希望素材来源和使用在文档里写清楚。
22. 作为设备主人，我希望预览命令能直接渲染六动作与新版式，方便确认。
23. 作为设备主人，我希望真机上看到的和预览一致。
24. 作为设备主人，我希望动作切换时才重绘，不为了动画每帧刷屏。
25. 作为设备主人，我希望睡觉动作只在长时间无任务时出现。
26. 作为设备主人，我希望错误/停止状态都有明确表情，而不是共用一张图。
27. 作为设备主人，我希望六张图的头身比例、描边粗细一致，看起来是同一只。
28. 作为开发者，我希望素材只改文件与缩放参数，不改贪心矩形化逻辑。
29. 作为开发者，我希望有测试保证六动作素材存在、尺寸 90×120、有墨、不越界、互不相同。
30. 作为开发者，我希望版式测试断言品牌行同时包含中文与英文、且不重叠。
31. 作为开发者，我希望预览图和真机照片作为验收证据写进 SPEC。
32. 作为开发者，我希望素材生成过程可复现（脚本 + PNG 入库）。
33. 作为开发者，我希望旧 30×40 占位图与旧图标被完全替换。
34. 作为开发者，我希望版本号递增到 0.6.1，并同步插件 package.json 与 SPEC。
35. 作为未来维护者，我希望参考图、风格规则、素材契约集中在一处。
36. 作为未来维护者，我希望 ADR 记录「30×40@3× → 90×120@1×」这次契约变更的原因。

## Implementation Decisions

**切面（seams）**：不新增切面。改动点集中在既有素材契约 `assets/croc/<outfit>/<action>.png`、`sprite::draw_action` 的缩放参数、`layout::draw` 的品牌行，以及 `src/sprite.rs` / `src/layout.rs` 现有测试。插件协议、状态机、刷新策略、配置桥均不改。

**素材契约 v2**
- 物种：gator / 短吻鳄（alligator）——吻部短、宽、圆，上颌盖住下颌，牙齿多数藏在唇内，头部像圆角方块；**不要画长 V 形吻、不要画外露鳄齿排**。
- 尺寸 90×120，单色（`L` 模式），透明或白底均可，阈值 <128 视为墨。
- 渲染 `sprite::draw_action(e, 300, 150, action, 1)`，1:1 绘制，不再放大。
- 描边 2px 实心黑，头部约占身高 45%，眼睛有 2×2 白色高光，肚皮用 2–3 条 1px 横线；头身比 chibi（头大身小）。
- 六动作：`idle` 端咖啡杯；`working` 敲笔记本；`waiting` 举手 + 问号；`done` 星星 + 微笑/点赞；`error` 绷带 + × 眼；`sleep` 闭眼 + Z。
- 停止（Stopped）继续复用 error 动作（既有决定）。

**品牌行版式**
- 第一行中文「鳄鱼大宠物」12px（基线 16），第二行英文「Zetrix / DSH pet」9px（基线 28），右侧模式徽章位置不变。
- 分隔线由 y=30 下移到 y=34；多任务 heading 基线下移 2px；单任务 headline/标题/详情/进度条/等待徽章/底部整体保持现有相对关系，仅整体下移 4px 以内，确保底部信息仍在分隔线之上。
- 英文名是副行，视觉权重低于中文，高于底部注脚。

**图标与文档**
- `plugin/icon.png` 用新鳄鱼头像重绘（128×128，单色，白底）。
- README 头图与 `docs/screens/*.png` 用新素材重渲染。
- `docs/reference/croc-style/` 保留 3 张参考图，注明「用户提供的风格参考，不直接复制」。
- 版本 Cargo 与插件 package.json 同步 0.6.1；SPEC 增加 FR-CROC-05「形象 v2 风格基线」，更新 FR-CROC-01/02/03、FR-UI-05 证据。
- 新增 ADR 0007 记录素材契约变更（30×40@3× → 90×120@1×）及理由（细节可读性、用户决定）。

**接口**：`sprite::draw_action(elements, x, y, action, scale) -> usize` 签名不变；`ACTIONS` 不变；素材目录约定不变；`layout` 对外仍是 `draw(model, frame) -> Value`。

## Testing Decisions

- 好测试只验证外部行为：素材存在、尺寸正确、可解码、墨量合理、六动作互不相同、未知动作不画、场景不越界；不比对逐像素（手绘素材会微调）。
- 模块：`sprite` 素材加载与绘制；`layout` 品牌行文本与几何位置；`preview` 输出可渲染。
- 复用先例：`src/sprite.rs` 的 `all_actions_have_art`、`unknown_action_draws_nothing`；`src/layout.rs` 的 `layouts_obey_hub_limits`、`header_is_brand_only_and_idle_footer_reports_device`。
- 新增断言：素材 90×120；每动作墨点比例 6%–50%；包围盒宽高 ≥ 40×60；六动作矩形集合两两不同；页头文本同时包含「鳄鱼大宠物」与「Zetrix / DSH pet」，且英文基线 < 分隔线 < 状态大字基线。
- 视觉验收：`preview --demo <state>` 六张 PNG 与参考图比对；真机推六状态各一张。
- 性能：贪心矩形化后单帧元素数上限 **400**（90×120 素材实测 218–284，原「<220」目标已上调；见 `src/layout.rs` 的 `layouts_obey_hub_limits`；再高应简化素材而不是拆动作）。

## Out of Scope

- 彩色墨水屏、gray4/gray16 专属形象、逐帧动画/眨眼。
- 新动作；装扮（outfit）内容实现（只保留机制）。
- 插件设置页、生命周期、手势、语音。
- 英文产品名在插件商店/README 之外的品牌系统（如 logo 字体规范）。

## Further Notes

- 三张参考图关键特征：薄荷绿 gator（短吻鳄）、圆头短圆吻、黑粗描边、白色高光眼、浅色肚皮、夸张表情（咖啡师「早上好」、点赞「奈斯」、打工「沉迷工作」）。v2 取造型语言（尤其「短圆吻 + 圆头」这个 gator 特征），不描摹画面。
- 历史命名说明：资产目录 `assets/croc/...`、插件包名 `zectrix-croc-pet`、FR-CROC-* 编号沿用早期命名；实际角色物种是 gator，若整体改名属独立改动，本次不改路径/包名。
- 单色墨水屏：素材直接画黑白实心形状，不用灰阶抗锯齿；预览时按阈值渲染，和真机一致。
- 90×120 下建议先画 idle，再以同一头身模板派生其余五张，保证是同一只。
- 若某动作在 90×120 仍辨识不足，优先简化道具/姿势，不改尺寸；确需改动再开 ADR 并回改 spec。

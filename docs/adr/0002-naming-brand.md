# ADR 0002：产品命名与品牌头

- 状态：Accepted（2026-11-18）
- 相关：FR-UI-05、FR-REL-01

## 决策

- 正式名称：**鳄鱼大宠物**（五个汉字，中文语序，略带玩笑感）。
- 英文/仓库名：`zectrix-croc-pet`；内部 crate 名暂时仍为 `dsh-pet`（避免大范围重命名），可执行文件仍为 `dsh-pet.exe`。
- 项目名：`zectrix-deepseek-harness-pet`（文档/仓库描述使用）。
- 宠物无自称、无名字；界面不出现「AI 工作搭子」。
- 设备左上只显示「鳄鱼大宠物」12px；窗口标题、DSH 插件标题、插件图标名都用该名称。
- 归属：fork 自 MuskCheng/zectrix-workbuddy-pet（MIT），保留原作者版权声明，新增部分同 MIT。

## 理由

用户要求「新的产品名 + 精简左上产品名与副标题」；五字在 400×300 上以 12px 一行可容纳（约 60px），不挤占标题区。英文只在仓库/包名使用，避免设备顶部双语拥挤。

## 后果

- 旧文档/截图中的「DSH 宠物」「AI 工作搭子」需全量替换。
- 若将来要改英文品牌名，只影响 README/仓库，不影响设备版式。

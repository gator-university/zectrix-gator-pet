# ADR 0004：屏幕刷新格式与合并推送

- 状态：Accepted（2026-10-30，沿用）
- 相关：FR-DEV-02..04

## 背景

Zectrix Note 4 的 gray16 整屏刷新实测 4–5 秒且多段波形看起来连续闪烁；mono 约 1–2.4 秒，gray4 约 3.5 秒。

## 决策

- 默认 `mono`；设置页可切 `gray4`/`gray16`（高级项）。
- 连接设备后先等 1.2 秒让固件切完界面，再最多 4 轮×450ms 等到状态稳定才推首帧。
- 推送最小间隔 3 秒（`PUSH_COOLDOWN_SECS=3`），冷却期内变化合并为最后一次状态。
- 画面指纹去重：同一画面不重复推送。
- 完成画面固定 5 秒后回待命，再按 grace 交还设备。

## 后果

- 状态变化到上屏最多约 3–5 秒延迟，换取明显更少的整屏闪烁。
- 若用户选择 gray16，闪烁会变多，属于用户显式选择。

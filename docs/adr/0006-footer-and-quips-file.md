# ADR 0006：底部两态信息与可替换花絮

- 状态：Accepted（2026-11-18）
- 相关：FR-UI-06、FR-UI-07

## 决策

- 底部区域永远保留（不因空间隐藏），左右两块常驻：
  - 有任务：左「上下文 N% · 剩 MK」，右花絮。
  - 空闲：左「电量 N% · Wi-Fi 良好/一般/弱」，右「等你派活」。
- 花絮来源：`assets/quips.txt`（UTF-8，一行一句，≤20 字），启动时读取；文件缺失或空则用内置池。用户可直接替换文本，重启宠物进程生效。

## 理由

用户要求左下/右下固定文案，并希望花絮句子以后能自己替换；文本文件是最低门槛的替换方式。

## 后果

- 打包插件时必须把 `assets/quips.txt` 列入 `files`，否则安装后读不到。
- 花絮只在有任务时出现，空闲时右下固定「等你派活」。
